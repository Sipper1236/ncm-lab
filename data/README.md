# Training data

The NCM coding agent uses synthetic, grouped action traces generated by
`python scripts/prepare_agent_pairs.py`. Each episode covers a short Python
stdin-to-stdout task and includes calls to write, run, and sometimes repair one
script. Repair traces include runtime errors, syntax errors, and wrong-but-
running output; expected values stay out of training prompts. Example runs use
Bubblewrap, with network disabled and a temporary workspace. No external agent
traces are downloaded.

The older instruction-to-code experiment uses `python
scripts/prepare_code_pairs.py` to download the corpus listed in
[`SOURCES.md`](SOURCES.md) and create `pairs.jsonl`. That file contains
natural-language prompts paired with Python source, not agent actions.

Generated corpora, downloaded sources, and local files are ignored by Git.
Keep only data you are allowed to use, and do not add private files or secrets
to a corpus.
